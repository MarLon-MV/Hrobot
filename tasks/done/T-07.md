# T-07: Guardado de mapas, ampliación de mapas y correcciones pendientes

- **Rama Git:** `feat/autonomous-exploration`
- **Depende de:** T-05
- **Commit:** `feat(explorer): ...` (+ `fix(interfaces): ...` si se separa)

## Objetivo
1. **Guardar mapas.** Nuevo ejecutable `map_manager_node` en `create3_autonomous_explorer` que implementa el servicio `save_exploration_map` (`create3_bot_interfaces/srv/SaveExplorationMap`):
   - Llama a `nav2_msgs/srv/SaveMap` (servicio `/map_saver/save_map`) para generar `<dir>/<nombre>.yaml` + `.pgm`.
   - Llama a `slam_toolbox/srv/SerializePoseGraph` (servicio `/slam_toolbox/serialize_map`) para generar `<dir>/<nombre>.posegraph` + `.data`, que permite **ampliar** el mapa más adelante.
   - Directorio configurable (`maps_dir`, por defecto `~/.create3_maps`, se crea si no existe); `map_name` vacío genera nombre con marca de tiempo; el nombre se sanea (sin `/`, `..`, espacios).
   - Responde `success`, `map_path` (sin extensión), `posegraph_path` y `message` con el motivo de cualquier fallo; no lanza excepciones; tolera que Nav2/slam_toolbox no estén disponibles (timeout parametrizable).
2. **Lógica pura testeable** (sin ROS) en la lib: `map_naming.hpp/.cpp` (sanear nombre, generar nombre por timestamp inyectado, componer rutas). Tests GoogleTest.
3. **Ampliar mapas.** El mecanismo es slam_toolbox cargando el posegraph al arrancar (`map_file_name` + modo mapping), configurado en T-06. Aquí: `ExplorerNode` guarda al terminar (`save_map_on_finish` por defecto `true`) y el resultado devuelve `map_path`. Documentar en el README del paquete cómo reanudar.
4. **Correcciones pendientes:**
   - `create3_bot_interfaces`: declarar `action_msgs` en `package.xml` (`depend`) y `find_package(action_msgs REQUIRED)` en CMake; ampliar `SaveExplorationMap.srv` con `string posegraph_path` en la respuesta.
   - `ExplorerNode`: sacar el logging que se hace con el mutex tomado (guardar el mensaje y loguear fuera del lock).
   - Parámetros `double` documentados como `1.0`.
